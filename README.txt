To preview: double-click index.html to open it in your browser.
To publish: upload the whole folder (keep the files together) to any web host,
e.g. Netlify, GitHub Pages, or your existing hosting via FTP.

To add a new blog post: copy blog-bigfoot-in-a-pringle-jumper.html, rename it,
replace the title and text, then add a card for it at the top of blog.html.
